# Charte du projet

> **Template** : 03.I · **Phase** : 01 Lancement · **Gate** : RfP

> enrichit chaque champ avec la traduction RTBF du template Word d'origine.

## 1. Contenu

### 1. Objectifs et périmètre (dans / hors)

**Objectif** : fournir un kit Markdown + protocole agent pour constituer et
mener un projet selon PM² (1 projet = 1 folder).

- **Dans le périmètre** : templates PM², checklists (gates + rôles), agent de
  routage IA (`AGENT-projet.md`), outillage natif (`assistant.ps1`/`.sh`).
- **Hors périmètre** : le fork « configuré » pour le contexte RTBF (dérivé, GitLab — voir PM2-02 §2-3) ; ce repo reste public et générique.
(source : `_meta/fiche.md` §1)

### 2. Résultats attendus et critères

Voir PM2-01 §4-6 : **utilisable pour tous (GitHub) · pour la RTBF (GitLab) · utilisé sans obligation** (validé 06/11).

### 3. Parties prenantes clés et rôles (Sponsor, BM, Chef de projet, Fournisseur)

- **Porteur (ctg)** : assume sponsor / BM / CP pour l'instant (projet mené seul, confirmé 06/11).
- **Challengers** : identifiés dans l'échange du 06/11 (temps mobilisé) — **rôle exact à confirmer**. `[À confirmer]`
- `_meta/registry/roles.md` à créer quand les rôles seront confirmés.
(source : `_meta/fiche.md` §2-4 + session du 06/11)

### 4. Jalons prévisionnels

**Objectifs sans dates** (formulation de l'utilisateur, 06/11 — « peut-être pas des jalons dans le langage ») :
1. Démos individuelles pour promoteurs
2. Démo publique (interne)
3. Annonce publique
4. Présentation à l'EU
5. Utilisation réelle sur mes projets
6. Utilisation réelle sur des projets RTBF **pas à moi** (et **sans moi**)

**Instances à dates nommées** (suivi) : comités **IA**, réunions **PMO**, réunions **COP Projet** — dates à recenser. `[À confirmer]`
(source : session du 06/11)

### 5. Risque principal

- **Risk 1** : opposition des « **pro Copilot** ».
- **Risk 2** : peur, côté **décideurs/sponsors**, d'une interface **trop geek**.
(source : session du 06/11)

### 6. Budget d'ordre de grandeur

- **Temps** : porteur + challengers ; bonus : temps pour de l'aide.
- **IA** : budget token IA interne + éventuellement module Copilot Pro. Pas d'enveloppe monétaire.
(source : session du 06/11)

**2026-10-26** (création de `_meta/fiche.md`). Aucun go/no-go formel n'a été
prononcé.
