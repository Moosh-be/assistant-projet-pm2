# registry/abreviations.md — fil pédagogique des abréviations (feedback 1, 10/11)

**Règle** : 1re occurrence dans un document ou un échange = **nom complet (abréviation)**.
**Assimilation** : l'interlocuteur a assimilé une abréviation quand **il** l'a
utilisée **3 fois** dans les échanges (ou l'a demandée explicitement) → statut
passé à « assimilée » = **on peut utiliser l'abréviation seule** avec lui.
Chaque changement de statut est noté ici, avec sa preuve (`source`).
