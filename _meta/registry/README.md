# _meta/registry/ — registres

- `roles.md` — qui fait quoi sur ce repo (sponsor / bm / cp)
- `connexions.md` — registres des connexions **du projet** (ids `sp_project` / `op_id` / MCP)
- `decisions.md` — décisions structurantes (1 ligne : date + décision + source)

> La **config machine** (racines, connexions transversales) ne vit plus ici : elle est dans `.assistant.config` à la racine du kit (WP-0017), et les secrets dans `.assistant-projet.env`.

Règle : un fichier de registre est créé **quand le premier contenu arrive** — pas de fichier vide.
