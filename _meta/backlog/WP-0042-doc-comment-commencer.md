# WP-0042 — Doc « Comment commencer »

## Objectif

Une doc d'**onboarding** qui raconte le premier contact avec l'assistant **comme si on partait
d'une machine neuve** : rien d'installé, aucun projet existant, hors 2ndb. Chaque étape est
taguée **✅ aujourd'hui / 🔜 à venir (WP)** — rien d'inventé : le 🔜 est du tracé, pas une promesse.

## Critères de réalisation

- [x] `docs/comment-commencer.md` écrite : trame 9 § (repo → démarrage → opencode → inventaire → méthodes → outils → scan → changement de root → espace disque) + récap ✅/🔜
- [x] Pointeurs : `docs/guide.md` §2 (Installation) + `README.fr.md` (ligne « Parcours complet »)
- [ ] **Validation par l'utilisateur** — incluant les 2 `[À confirmer]` de la doc :
  - PgM² = « programmes » (cohérent PfM²/PM²/PgM²) ou le verbatim « pour les projets » ?
