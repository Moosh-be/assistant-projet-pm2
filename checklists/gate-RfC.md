# Checklist de gate — RfC (Ready for Closure / Prêt pour la Clôture)

> **À valider avant de passer en Clôture.** Une case rouge = l'Exécution n'est pas terminée.
> Source : transposition du PM2-27 — version générique.

## Livrables
- [ ] Tous les **livrables du périmètre** produits
- [ ] **Acceptation formelle** de chaque livrable (selon le PM2-08) — acceptations signées
- [ ] Non-conformités : traitées ou acceptées explicitement

## Transition
- [ ] **PM2-09** Transition : transfert à l'exploitation **effectif** (compétences formées, données, outils)
- [ ] Documentation d'exploitation remise
- [ ] Support / exploitation identifié et prêt

## Conclusions
- [ ] **PM2-19/22** Rapport d'état final : feux verts (ou déviations acceptées)
- [ ] Budget et planning **finals** consolidés (écart vs baseline expliqué)
- [ ] **Leçons apprises** collectées (bien / mal / à éviter)
- [ ] Ressources libérées / déchargées

## Verdict
- [ ] **PASSAGE EN CLÔTURE** — signé : __________ — date : __________
- [ ] **PM2-33** Rapport de fin de projet : à produire en Clôture
