# Checklist de gate — RfP (Ready for Planning / Prêt pour la Planification)

> **À valider avant de passer en Planification.** Une case rouge = la phase Lancement n'est pas terminée.
> Source : transposition du PM2-27 (Liste de contrôle de sortie de phase) — version générique.

## Artefacts du Lancement (dus)
- [ ] **PM2-01** Demande de lancement — complétée + signature du demandeur
- [ ] **PM2-02** Cas d'usage / business case — complété, valeur chiffrée
- [ ] **PM2-03** Charte du projet — complétée, approuvée par le Sponsor

## Décision & rôles
- [x] **Go/no-go** décidé par le Sponsor (date + décision consignée) — GO, ctg, 2026-11-09 (PM2-03 §7)
- [ ] **Sponsor** identifié **et actif**
- [ ] **Business Manager** identifié (représentant du Sponsor au quotidien)
- [ ] **Chef de projet / gestionnaire** désigné
- [ ] **Fournisseur / MOE** identifié (et distinction MOE ≠ gestionnaire)
- [ ] Rôles recommandés envisagés : SPO (méthodologue) · QAM (qualité)

## Cadrage
- [ ] Périmètre **dans / hors** écrit noir sur blanc
- [ ] Critères de succès définis (mesurables)
- [ ] Risque principal identifié + première réponse
- [ ] Budget d'ordre de grandeur posé
- [ ] Méthode choisie et **appropriée** (PM² / Scrum / ARACH)

## Verdict
- [ ] **PASSAGE EN PLANIFICATION** — signé : __________ — date : __________
