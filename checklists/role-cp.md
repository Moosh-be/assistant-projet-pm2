# Checklist du Chef de projet (CP) — par phase

> Le minimum vital du CP, phase par phase. Complément du skill « démarrer un projet » (12 étapes).

## Lancement (→ RfP)
- [ ] Projet ajouté au **référentiel des chantiers** (il « existe » officiellement)
- [ ] Demande d'initialisation remplie (même si acquis)
- [ ] Fiche projet créée (l'embryon — le CP n'en est pas encore responsable)
- [ ] Méthode **appropriée** (PM² / Scrum / ARACH) — pas subie
- [ ] Les **4 rôles piliers** identifiés : Sponsor · BM · CP · Fournisseur (MOE)
- [ ] Espace de gouvernance (Obeya numérique/physique/hybride)
- [ ] **WBS** (grosse découpe) + **RBS** (ressources — c'est le **Sponsor** qui les obtient, pas le CP)
- [ ] Charte approuvée → **RfP**

## Planification (→ RfE)
- [ ] Manuel du projet (règles du jeu)
- [ ] Parties prenantes + stratégies
- [ ] Plan de travail (jalons, séquences, dépendances)
- [ ] **Chaque** plan de gestion envisagé : `utilisé / ignoré` **décidé** (anti-surcharge)
- [ ] Baseline budget + planning approuvées → **RfE**

## Exécution
- [ ] Coordination des travaux (le CP **planifie**, les ressources exécutent)
- [ ] PV de chaque réunion structurante (PM2-18) — décisions + actions datées
- [ ] Reporting périodique (PM2-19/22) — feux + prochaine décision demandée
- [ ] Changements : via la démarche (PM2-21), jamais « en glissement »
- [ ] Risques revus au rythme défini (PM2-13)

## Clôture (→ RfC)
- [ ] Livrables acceptés (PM2-08)
- [ ] Transition effective (PM2-09)
- [ ] **PM2-33** Rapport de fin : objectifs atteints / leçons apprises / transfert confirmé
- [ ] Clôture administrative : ressources libérées, projet archivé
