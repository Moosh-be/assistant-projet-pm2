# Checklist de gate — RfE (Ready for Execution / Prêt pour l'Exécution)

> **À valider avant de passer en Exécution.** Une case rouge = la phase Planification n'est pas terminée.
> Source : transposition du PM2-27 — version générique.

## Artefacts de la Planification (dus)
- [ ] **PM2-04** Manuel du projet — règles du jeu + gouvernance écrites
- [ ] **PM2-05** Matrice des parties prenantes — complète + stratégie par partie prenante
- [ ] **PM2-06** Plan de travail — découpe (WBS) + jalons + séquences
- [ ] **Plans de gestion envisagés** — pour CHAQUE plan (11-16) : statut `envisagé / utilisé / ignoré` **décidé** (pas « pas encore regardé »)

## Capacité & ressources
- [ ] **Ressources** confirmées par le Sponsor avec le Fournisseur (RBS)
- [ ] **Collaborateurs planifiables** nommés (le CP planifie ensuite)
- [ ] **Budget baseline** posé (+ marge de gestion)
- [ ] **Planning baseline** posé (jalons non négociables identifiés)

## Risques & qualité
- [ ] **PM2-13** Risques : registre initial (3-5 majeurs) + réponses + propriétaires
- [ ] **PM2-08** Acceptation des livrables : critères + démarche de recette définis
- [ ] **PM2-09** Transition : conditions de bascule identifiées (même esquissées)

## Verdict
- [ ] **PASSAGE EN EXÉCUTION** — baseline approuvée — signé : __________ — date : __________
